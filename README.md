# Guess The Number: Ultimate Edition

## Overview
A robust, feature-rich terminal game built in Python. This isn't just a simple loop; it includes persistent profiles, an achievement system, and dynamic ASCII art for a complete retro-arcade feel right in your console.

## Features
- **Persistent Profiles:** Automatically saves your scores and stats to a local JSON file.
- **Local Leaderboards:** Compete against other profiles saved on the same machine.
- **Multiple Difficulties:** Easy, Medium, Hard, Extreme, Nightmare, and Custom.
- **Dynamic Hints:** Spend points to get mathematical hints (evens/odds, multiples).
- **Achievements:** Unlock badges for flawless victories, high scores, and more.

## Technologies Used
- **Language:** Python 3.x
- **Libraries:** `random`, `json`, `os`, `time` (Standard Library only, no external dependencies)
