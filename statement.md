# Problem Statement
Traditional number guessing games are often simple, text-based scripts that lose player interest after a single round. There is a need for a more engaging terminal-based application that offers replayability through persistent progression, varying difficulties, and dynamic feedback.

# Scope of the Project
This project is a modular Python-based terminal game. It features persistent data tracking (JSON), multiple difficulty tiers, a dynamic hint system, an achievement/badge engine, and a local leaderboard. 

# Target Users
- Casual gamers looking for a quick terminal-based puzzle.
- Programming students reviewing basic Python game loops and modular design.

# High-Level Features
- 5 distinct difficulty modes plus a Custom ruleset generator.
- Persistent player profiles tracking wins, win rates, and points.
- A local leaderboard to compare scores across different profiles.
- Dynamic  taunts and motivational phrases based on RNG.
- Achievement unlocking system for specific gameplay milestones.
